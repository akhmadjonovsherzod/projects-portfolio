# Fond Rouge Data Analysis

A data analysis project developed in **SAP Analytics Cloud (SAC)** for Fond Rouge, a European luxury brand operating across 15+ cities.

## Project Overview

The analysis explores:

- Revenue performance by location
- Order returns and refund trends
- Refund-to-revenue ratios
- Customer sentiment
- Potential problem areas in the US

A key focus was combining **customer sentiment** with **refund-to-revenue ratios** to identify locations requiring further investigation. The analysis highlighted potential quality issues in **San Diego** and possible counterfeit-related issues in **Los Angeles and Las Vegas**.

## Tool

**SAP Analytics Cloud (SAC)**

The dataset was processed, analyzed, and visualized in SAP Analytics Cloud using charts, maps, and dashboards.

## Key Metrics

- Revenue by city/country
- Refund amount and refund rate
- Refund-to-revenue ratio
- Average customer sentiment
- Location-level performance
